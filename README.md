# ⚡ NEON RUSH

### Enter the Neon. Survive the Rush.

A cyberpunk-inspired arcade game built with **HTML, CSS, and JavaScript**. Experience a futuristic neon world with immersive audio, dynamic environments, and interactive gameplay.

## 🌌 About the Game

NEON RUSH brings the atmosphere of a futuristic arcade into your browser. This project combines game logic, custom visual design, audio effects, and an immersive cyberpunk aesthetic.

## ✨ Features

- 🎮 Interactive browser-based gameplay
- 🌃 Cyberpunk-inspired neon visuals
- 🔊 Dedicated audio system
- ⚙️ Modular JavaScript architecture
- 🎨 Custom interface and styling
- 💻 Built with standard web technologies

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- SVG

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone -b neon-rush-new https://github.com/Haima18/neon-rush.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

Alternatively, open the folder in VS Code and use the Live Server extension.
